7.3 【例7 - 1】设有Student(学生)，Course(课程)，SC(学生选课)3个关系，关系模式如下 （具有下划线的属性是关系的主键，且S#，C#都是关系SC上的外键）： Student(S#，Sname，Sex，Class) Course(C#，Cname，Teacher) SC(S#，C#，Grade)
在例7 - 1中查询语句为：找出选修李明老师所教课程并且成绩为优的女生学号和姓名。
(1)试写出该查询相应的关系代数表达式。
(2)画出表达式的语法树并对其进行优化。
解：
(1)试写出该查询相应的关系代数表达式。
$$ П_{\text{S\#, Sname}} \left( \sigma_{\text{Sex='女'}}(Student) \Join \left( \sigma_{\text{Grade='优'}}(SC) \Join \sigma_{\text{Teacher='李明'}}(Course) \right) \right) $$
(2)画出表达式的语法树并对其进行优化。
   ```
                П_S#,Sname
                     |
                     ⋈
                   /    \
σ_Sex='女'(Student)     ⋈
                        /     \
          σ_Grade='优'(SC)  σ_Teacher='李明'(Course)
   ```    
优化后的语法树
```*
          П_S#,Sname
               |
             ⋈_{S#}
           /         \
  П_S#,Sname           ⋈   
      |             /       \
  σ_Sex='女'       П_C#   П_S#,C#
      |             |         |
  Student   σ_{Grade='优'}   σ_{Teacher='李明'}
                    |          |
                   SC         Course
```
优化后的关系代数表达式如下：
$$ \pi_{\text{S\#, Sname}} \left( \pi_{\text{S\#, Sname}} \left( \sigma_{\text{Sex='女'}}(Student) \right)  \bowtie\pi_{\text{S\#}} \left( \sigma_{\text{Grade='优'}}(SC) \bowtie 
\pi_{\text{C\#}} \left( \sigma_{\text{Teacher='李明'}}(Course) \right) \right) \right) $$

7.4 在例7 - 1中，关系Course在Cname属性上有有序索引，Teacher属性上有无序索引。实现下列选择运算的较优化方法是什么？
(1)$\sigma_{\text{Teacher = '李明'}}(E)$。
(2)$\sigma_{\text{Cname = '数据库系统' and Teacher = '李明'}}(E)$。 
(3)$\sigma_{\text{Cname = '数据库系统' or Teacher = '李明'}}(E)$。
答：
(1)
由于Course关系中Teacher属性上有无序索引，数据库可以直接使用该索引快速定位满足条件的记录。这种方法避免了全表扫描，效率较高，尤其适合等值查询。
(2)
Course关系上有Cname的有序索引和Teacher的无序索引。方法一：可以选择先使用Cname的索引查找Cname = '数据库系统'的记录，然后过滤Teacher = '李明'，或反之，取决于哪个条件的记录更少（即选择性更高）。
方法二：可同时使用两个索引并行执行，通过 Cname 的有序索引找到 Cname='数据库系统' 的元组集合 A，通过 Teacher 的无序索引找到 Teacher='李明' 的元组集合 B，A ∩ B即为结果
(3)
由于是OR条件，建议将查询拆分为两个部分并行执行：一个查找Cname = '数据库系统'，另一个查找Teacher = '李明'，然后使用UNION合并结果。这样，每个部分可分别使用Cname的有序索引和Teacher的无序索引，避免OR条件导致的性能下降。

7.5 在习题7.3中，关系Course有20 000个元组，块因子为20；关系SC有400个元组，块因子为10；假设内存被划分为6块，关系Course和SC的连接属性有序存储。对于Course⋈SC运算，试分析下列两种方法所需访问的物理块数。
(1)用嵌套循环连接算法。
(2)用排序归并连接算法。 
答：
由题意可得：
Course：20,000个元组，块因子20 
可得Course总块数=20,000/20=1,000 块
SC：400元组，块因子10
可得SC总块数= 400/10=40 块
内存块数：6 块
(1) 
内存块数：6 块，6-1=5 块用于外层
选择元组少的SC作为外层
外层的块数=SC总块数=40 块，批次=40÷5=8。 
内层的块数=Course总块数=1000 块
Course扫描全表共8×1000=8000 块
总物理块访问数=40+8000=8040 块
 （2）
只需扫描Course和SC各一次
Course的读取：顺序扫描一次，访问块数=1,000 块
SC的读取：顺序扫描一次，访问块数=40 块
总物理块访问数=Course访问+SC访问=1000+40=1040 块
