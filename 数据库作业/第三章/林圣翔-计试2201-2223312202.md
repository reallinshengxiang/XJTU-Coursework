# 第三章习题
1、以下定义的是某汽车修理厂管理系统数据库，其中加下划线的为关系模式主键，斜体字为外键。该修理厂雇用若干名修理工并划分为不同的班组，汽车维修以班组为单位进行，每个班组安排一名修理工作为组长负责分配给该组的汽车维修事宜。
・修理工($\underline{\small{工号}}$，姓名，年龄，参加工作时间，_班组号_)  
・班组($\underline{\small{班组号}}$，人数，_组长工号_)
・汽车($\underline{\small{车牌号}}$，车主姓名，车型，联系电话)
・维修($\underline{\small{维修记录编号}}$，_车牌号_，_班组号_，维修时间，收费)
试对这个关系数据库写出如下SQL查询：
1)查询该修理厂划分的维修班组总数   
2)查询各维修班组的班组号及其组长姓名     
3)查询车牌号为“V0075”的汽车在“2019-01-01”至“2019-12-31”期间由修理工“E029”所在班组进行维修的费用总额  
4)将修理工“E010”所在分组编号调整为“T03” 
答：
1)
SELECT COUNT(*) AS 维修班组总数
FROM 班组;
2)
SELECT 班组.班组号, 修理工.姓名 AS 组长姓名
FROM 班组
JOIN 修理工 ON 班组.组长工号 = 修理工.工号;
3)
SELECT SUM(维修.收费) AS 费用总额
FROM 维修
JOIN 班组 ON 维修.班组号 = 班组.班组号
JOIN 修理工 ON 班组.组长工号 = 修理工.工号
WHERE 维修.车牌号 = 'V0075'
  AND 维修.维修时间 BETWEEN '2019-01-01' AND '2019-12-31'
  AND 修理工.工号 = 'E029';
4）
UPDATE 修理工
SET 班组号 = 'T03'
WHERE 工号 = 'E010'; 

 
 
 
2、以下定义的是某手机话费充值卡管理系统数据库，其中加下划线的为关系模式主键，斜体字为外键。每张充值卡通过卡号及密码为手机号码充值，一张充值卡只能为一个手机号码充值且一次充值过程必须消费完卡上的所有金额。每个手机号码只属于一个机主，而每位机主可以拥有多个手机号码。
・充值卡($\underline{\small{卡号}}$，密码，面额，是否已售出)
・手机($\underline{\small{手机号码}}$，开户时间，开户地点，_机主编号_)
・充值($\underline{\textit{\small{卡号}}}$，_手机号码_，充值时间)
・机主($\underline{\small{机主编号}}$，姓名，身份证号码，联系地址，联系方式)
对这个关系数据库写出如下SQL查询：
1)查询尚未售出(是否已售出属性取值为“否”)的充值卡张数  
2)查询“刘”姓手机机主的姓名及持有的手机号码  
3)查询开户地点为“西安交通大学”的所有手机号码在“2019-11-01”至“2019-11-30”期间的充值总额  
4)将卡号为“SX010323”的充值卡面额增加一百元 
答：
1）
SELECT COUNT(*) AS 未售出充值卡张数
FROM 充值卡
WHERE 是否已售出 = '否';
2）
SELECT 机主.姓名, 手机.手机号码
FROM 机主
JOIN 手机 ON 机主.机主编号 = 手机.机主编号
WHERE 机主.姓名 LIKE '刘%';
3）
SELECT SUM(充值卡.面额) AS 充值总额
FROM 充值卡
JOIN 充值 ON 充值卡.卡号 = 充值.卡号
JOIN 手机 ON 充值.手机号码 = 手机.手机号码
WHERE 手机.开户地点 = '西安交通大学'
  AND 充值.充值时间 BETWEEN '2019-11-01' AND '2019-11-30';
4）
UPDATE 充值卡
SET 面额 = 面额 + 100
WHERE 卡号 = 'SX010323';

3、以下是某学生食堂就餐卡管理系统中的部分表，其中加下划线的属性为主键，斜体字属性为外键，每个学生只可办理一张就餐卡。
・学生($\underline{\small{学号}}$，姓名，性别，班级，出生年月)
・就餐卡($\underline{\small{卡号}}$，_学号_, 开户日期，失效日期，密码，余额，每日消费限额)
・POS终端($\underline{\small{POS编号}}$，地理位置)
・消费($\underline{\textit{\small{卡号}}}$，$\underline{\textit{\small{POS编号}}}$，消费日期，消费金额)
・充值($\underline{\textit{\small{卡号}}}$，充值时间，金额)
请写出关于这些表的如下SQL查询：
1)查询卡号为“053021”的就餐卡余额及每日消费限额 
2)查询编号为“018”的POS终端2010年12月的总收入  
3)查询“张蓓”同学2019年10月11日在编号为“029”的POS终端上的消费次数 
4)查询曾经在“西八食堂”(地理位置)就餐过的学生学号及姓名 
5)请为一名新入校同学增加其相关信息，学号：10054001，姓名：白杨，性别：女，班级：计算机01，出生日期：1992-11-08，该同学于2010-09-01办理的新就餐卡卡号为060567，
失效日期：2014-08-31，默认密码：123456，每日消费限额：50元   
答：
1）
SELECT 余额, 每日消费限额
FROM 就餐卡
WHERE 卡号 = '053021';
2）
SELECT SUM(消费金额) AS 总收入
FROM 消费
WHERE POS编号 = '018'
  AND 消费日期 BETWEEN '2010-12-01' AND '2010-12-31';
3）
SELECT COUNT(*) AS 消费次数
FROM 消费
JOIN 就餐卡 ON 消费.卡号 = 就餐卡.卡号
JOIN 学生 ON 就餐卡.学号 = 学生.学号
WHERE 学生.姓名 = '张蓓'
  AND POS编号 = '029'
  AND 消费日期 = '2019-10-11';
4）
SELECT DISTINCT 学生.学号, 学生.姓名
FROM 学生
JOIN 就餐卡 ON 学生.学号 = 就餐卡.学号
JOIN 消费 ON 就餐卡.卡号 = 消费.卡号
JOIN POS终端 ON 消费.POS编号 = POS终端.POS编号
WHERE POS终端.地理位置 = '西八食堂';
5）
